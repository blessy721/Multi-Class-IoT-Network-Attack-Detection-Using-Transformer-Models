### 🌐 Project Overview

An AI-driven cybersecurity project focused on detecting and classifying network attacks in Internet of Things (IoT) environments using Transformer-based deep learning models.

The project explores **TabTransformer and FT-Transformer** architectures to analyze network traffic patterns, distinguish normal traffic from malicious activities, and evaluate multi-class attack detection performance.

### 🎯 Project Objectives

- 🔍 Identify and classify different types of IoT network attacks.
- 🤖 Explore Transformer architectures for network intrusion detection.
- 📊 Evaluate model performance using classification metrics.
- 🧠 Analyze important network traffic features.
- 🔬 Compare model predictions and investigate classification errors.

### 📂 Dataset

**Dataset:** ToN-IoT

- 📊 Network traffic records: 209,340
- 🔢 Input features: 20
- 🔹 Numerical features: 17
- 🔹 Categorical features: 3
- 🎯 Classification categories: 9
- 🧪 Data split: 70% training, 15% validation, 15% testing
